---
name: Category-first task selection
description: The Track timer's task selection should follow the selected work category.
---

On the Track page, users choose a category first, then see active tasks for that category as inline choices rather than a global task dropdown.

**Why:** the user explicitly requested this flow to make it easier to choose a task under the selected category.

**How to apply:** preserve category-scoped, inline task choices when changing the Track timer's selection UI; reset the chosen task when the category changes.
