---
name: Recurring task behavior
description: User-defined schedule and completion expectations for recurring tasks.
---

Weekly recurring tasks allow selecting weekdays; monthly tasks allow selecting calendar dates. The repeat start and optional end date bound the schedule. A task remains one task entry: completing it moves it to “Will Recur” and it returns to active tasks on its next scheduled date. Weekday recurrence resumes on Monday.

**Why:** the user asked for day selection, a “Will Recur” section, and automatic return at the next scheduled start date.

**How to apply:** preserve this schedule and completion behavior when changing task storage, filtering, or recurrence UI.
